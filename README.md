# Tiny Gardener

[![Godot Engine](https://img.shields.io/badge/Godot-%23FFFFFF.svg?logo=godot-engine)][godot-engine]

[![Itch.io](https://img.shields.io/badge/itch.io-%23FF0B34.svg?logo=Itch.io&logoColor=white)][itch]

Tiny Gardener is a cozy game where you need to grow plants to fulfill a dream. There is a short story getting developed.

Please leave some feedback if you think this hobby game is worth continue to work on.

## Play Now

### On the web

To play the game on the web head over to [itch.io][itch] and give it a try in your browser. No installation required, start planting right away

Tiny Gardener is a hobby project, I am happy about any feedback provided.

### Installation

This part is empty as only the web version is getting shipped as of right now.

## Found a bug?

Report it on [GitHub][bug-report] by creating a issue, thank you in advance.

## Build the project

### Requirements

- [Godot 4.7][godot4_7]

### How to build the project

To build the project clone the repository to your machine. After cloning start Godot and open the `project.godot` file.
Use the import button inside of the Godot project overview to do so.

Now you should be able to run the game by starting the debug.
